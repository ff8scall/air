# 체크리스트 — 관심 지역 설정 기능

> 작성: 2026-05-04 | 상태: 승인 대기

## 구현 범위

1단계 (검색) + 2단계 (GPS) 순차 구현

## 데이터 흐름

```
[검색] 동 이름 입력
  → GET /api/resolve-station?umdName=오금동
  → fetchTmCoord(umdName) → tmX, tmY
  → fetchNearbyStations(tmX, tmY) → stationName 1순위
  → { stationName, regionName, lat, lng } → localStorage 저장
  → 페이지 리렌더 (새 측정소 기준으로 Hero/동네비교/지도 갱신)

[GPS] 위치 권한 동의
  → navigator.geolocation.getCurrentPosition
  → lat/lng → proj4 변환 → TM좌표
  → fetchNearbyStations → stationName
  → localStorage 저장 → 리렌더
```
